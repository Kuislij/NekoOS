# Проверка сохраняемого диска — 2026-09-25

Среда: WSL2, Ubuntu 26.04.1, QEMU 10.2.1, x86_64 TCG. Исходники собраны
обычным пользователем `neko` в Linux filesystem. Виртуальный диск — файл
`/home/neko/src/NekoOS/out/disks/state.img`, raw ext4, логический размер
512 МиБ; после проверки он занимал около 17 МиБ на хосте.

Проверки:

1. `bash os build` создал ядро и initramfs. Итоговая конфигурация ядра
   содержит `CONFIG_BLK_DEV=y`, `CONFIG_VIRTIO_BLK=y`, `CONFIG_EXT4_FS=y`.
2. `bash os test --no-build` прошёл: временная система загрузилась, shell
   перезапустился после `exit`, проверены каталоги, устройства, `neko-help`
   и штатное выключение (`BOOT_TEST_PASSED`).
3. `bash os test --disk --no-build` прошёл: маркеры записаны в `/root`,
   `/home`, `/var/lib`, пережили выключение и вторую загрузку, затем
   тестовые файлы удалены (`DISK_TEST_PASSED`). В обеих загрузках получено
   `PERSISTENCE_READY` и успешный `Power down`.
4. `bash os image` на существующем файле сообщил `existing; contents
   preserved` и не переформатировал его.
5. `bash os run` проверен вручную дважды: приглашение `neko#` появилось,
   рабочая папка — `/root`; созданный файл был прочитан после следующей
   загрузки и удалён. Обе сессии завершены через `poweroff`.

Физические диски Windows в VM не подключались. Данные `/etc`, `/usr`, `/tmp`
по-прежнему временные; эта проверка не означает готовность к установке ОС
на компьютер или к использованию как основной системы.
