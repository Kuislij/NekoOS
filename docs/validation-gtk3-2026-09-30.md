Приложение `neko-gtk-welcome` открывается через `bash os run --no-build --x11`;
с постоянного системного диска — через `bash os run --no-build --system --x11` после
обновления образа. Обычная заметка расположена в
`/home/neko/Documents/Neko-note.txt`. Self-test использует явно переданный
временный путь и не подменяет пользовательскую заметку.
Smoke-проверки запускаются на отдельных временных системном и
пользовательском дисках.

В процессе проверки устранена ошибка ввода: evdev определял virtio-tablet
как touchpad и переводил движения в относительный режим. В конфигурации
Xorg устройство теперь получает явное `Option "Mode" "Absolute"`.
Усиленный Xorg smoke сопоставляет реальное положение указателя с
координатами инъекции QEMU; в одноразовом графическом сеансе также проверены
обычный ввод текста и нажатие «Сохранить» без GTK self-test.
Усиленный input smoke щёлкает по редактору за открытым диалогом и
посылает дополнительный символ: после отмены и сохранения этого символа
в файле нет. Чистое закрытие завершает X11-сеанс; его сокет исчезает.

Локальные снимки проверки: `out/previews/gtk-input-saved.png` и
`out/previews/gtk-unsaved-dialog.png`. Они показывают сохранённую заметку
и настоящий GTK-диалог с отключённым родительским редактором; снимки
исключены из Git вместе с прочими результатами сборки.
