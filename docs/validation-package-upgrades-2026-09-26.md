# Проверка зависимостей и обновления — 2026-09-26

Среда: WSL2/Ubuntu, QEMU x86_64 TCG. `bash os build` создал initramfs с
NekoPkg/1, NekoPkg/2 и четырьмя демонстрационными архивами; проверка образа
приняла 1418 записей. Тест использовал отдельный временный ext4-диск,
существующий `out/disks/state.img` не подключался.

`bash os test --package --no-build --timeout 120` выполнил четыре загрузки.
Сначала был установлен пакет NekoPkg/1; его размещение приведено к старой
структуре диска. После перезагрузки менеджер прочитал эту установку.
Пакет `neko-companion` с требованием `neko-greet>=0.2.0` отказался
устанавливаться поверх `neko-greet` 0.1.0. Обновление до 0.2.0 прошло,
после чего зависимый пакет установился и запустился. Повторное обновление
до той же версии и установка при повреждённом файле зависимости были
отклонены. Попытка удалить
`neko-greet` при установленном зависимом пакете была отклонена.

Обновление `neko-greet` до 0.3.0 сохранило работу `neko-companion`.
`verify` обнаружил изменение исполняемого файла; после восстановления
проверка прошла. Пакеты удалены в правильном порядке. Последняя загрузка
подтвердила отсутствие пакетов и очистку имитированных остатков прерванной
операции: `PACKAGE_TEST_PASSED`.
