# Проверка системных пакетов и Pixman — 27 сентября 2026

Сборка выполнена в Ubuntu WSL2 как непривилегированный пользователь `neko`.
Рецепт Pixman 0.46.4 проверил SHA-256 и опубликованный upstream SHA-512
исходного архива и собрал разделяемую библиотеку против закреплённого musl.
Хостовый Meson 1.10.1 загружен с закреплённой контрольной суммой. Повторная
сборка дала тот же SHA-256 системного пакета:
`f3603aef6d717d23bd13f8a9d26198d77bb2265c98376ae6183f5ab9ba40d6d1`.
Размер пакета — около 1,3 МиБ, полного initramfs — около 4,7 МиБ.

Пять тестов `tests/test_system_package.py` прошли: постоянство архива,
установка нескольких пакетов с общими каталогами, запись манифестов,
проверка хешей, отклонение опасных путей, ссылок и конфликтующих файлов.
`bash os build` закончилось `BUILD_READY`; проверка образа приняла 1449 записей.
У программы `/usr/bin/neko-pixman-check` есть динамические зависимости
`libpixman-1.so.0` и `libc.so`, загрузчик musl и нет RPATH/RUNPATH.

Проверки на временных дисках и в QEMU:

| Проверка | Результат |
| --- | --- |
| `bash os test --no-build` | `BOOT_TEST_PASSED`, гостевая программа напечатала `PIXMAN_RUNTIME_READY` |
| `bash os test --system --no-build` | `SYSTEM_TEST_PASSED`, загрузка с отдельного системного диска |
| `bash os test --graphics --no-build` | `GRAPHICS_TEST_PASSED`, прежняя графическая оболочка продолжает работать |
| `bash os test --system-update --no-build` | `SYSTEM_UPDATE_TEST_PASSED`, обновление и откат с проверкой Pixman после обновления |

После этих проверок основной выключенный `out/disks/system.img` обновлён через
`bash os system-update --no-build`. Инструмент испытал копию диска с новым
Pixman, затем сохранил прежний образ как
`out/disks/system-backup-20260927T155003Z-ca677a74.img`.
Пользовательский `state.img` не подключался к проверке обновления: его SHA-256
до и после обновления совпал —
`6b248847da3052a45d25f4cef0657ce3628b5da20ba90383543fe429eedf7ce7`.

Системные пакеты пока включаются только при сборке образа. Pixman —
библиотека для будущего графического стека; Xorg, Xfce и Thunar ещё не собраны.
