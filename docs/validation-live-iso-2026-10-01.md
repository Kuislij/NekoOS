## Проверки работающей системы

Автоматический тест каждого режима проверяет:

- ISO загружается через свой BIOS/UEFI-загрузчик, без host `-kernel`/`-initrd`.
- Systemd, UID 1000 `neko`, парольный sudo, glibc, pacman, GCC и Firefox.
- Реальную компиляцию и запуск C-программы внутри гостя.
- Рабочий Xorg/Xfce-сеанс: видимые панели `DOCK`, фон `DESKTOP`, xfwm4 и Thunar.
- DHCP/default route и HTTPS-запрос из гостя.
- Настоящие события USB tablet; координаты X11 совпадают в пределах 4 пикселей.
- Каталог `neko-live-check` создаётся клавиатурой через диалог Thunar.
- При следующем запуске каталог отсутствует: Live-данные сброшены.
- Подключённый записываемый контрольный ext4-файл 64 МиБ не монтируется;
  после каждого выключения его SHA-256 совпадает с исходной.
- SSHD маскирован, корень `overlay`, Live-маркер присутствует.
- Systemd poweroff, код выхода QEMU 0, `Power down` в serial-логе.

Пользовательская VM и физические диски хоста не подключались. Это проверка
конкретного сценария; она не гарантирует отсутствие любых записей на любом
физическом оборудовании или после ручных действий через sudo.

Снимок BIOS CD просмотрен: русский Thunar, верхняя/нижняя панели Xfce,
созданный каталог и видимый контрольный диск, который не монтировался.
Снимки четырёх вариантов находятся в `out/previews/arch-live-<режим>.png`.

Первый Windows `.\Start-NekoOS.ps1 -Iso -Test` прошёл BIOS CD, UEFI CD
и BIOS USB; QEMU четвёртой загрузки завершился до serial-входа.
Поэтому этот прогон не засчитан как полный успех. Итоговый повтор:

```powershell
.\Start-NekoOS.ps1 -Iso -Test -Headless
```

Статус итогового повторного прогона: **пройдено**, код 0,
`NEKO_LIVE_ISO_TEST_PASSED`, все четыре режима. Итоговый JSON содержит
`internal_disk_unchanged: true`, `live_state_reset_between_boots: true`
и SHA-256 итогового ISO, указанный выше.
Логи — `build/logs/arch-iso-test-<режим>.log`, итог —
`build/logs/arch-iso-test-summary.json`. Итог содержит хэш проверенного ISO;
при начале следующего теста прежний успех заменяется статусом `running`.

## Оставшиеся ограничения

Физические GPU/Wi-Fi/звук, запись на реальную USB-флешку, Secure Boot,
установщик и сохранение Live-данных не проверены и не заявлены готовыми.
Нет каналов NekoOS stable/testing, отката Arch-обновлений, центра приложений
и адаптеров Debian/Ubuntu/RPM. Пакеты подписаны upstream; сам выпуск ISO
пока не имеет отдельной подписи и аттестации происхождения.
Полный комплект соответствующих исходников всех пакетов требует
отдельной подготовки перед публичным Release.
