# Проверка локальных программ и служб — 2026-09-25

Среда: WSL2, Ubuntu 26.04.1, QEMU x86_64 TCG, виртуальный диск ext4
`out/disks/state.img`. Существующий диск не форматировался и не заменялся.

1. `bash os build` создал initramfs с `neko-service`, списком загрузочных
   служб и сетевой службой. Проверка архива приняла 1408 записей.
2. `bash os test --no-build` подтвердил запуск `sysinit`, появление
   `SYSTEM_READY`, работу `neko-service list` и `status network`, консоли,
   компилятора C и штатного выключения: `BOOT_TEST_PASSED`.
3. `bash os test --disk --no-build` собрал C-программу в
   `/usr/local/bin`, выключил VM, загрузил её повторно и запустил программу
   по имени через PATH. Тест проверил и удалил только свои файлы:
   `DISK_TEST_PASSED`.
4. `bash os test --net --no-build` перезапустил сетевую службу, вновь получил
   DHCP-адрес и скачал файл по HTTP с локального сервера WSL:
   `NETWORK_TEST_PASSED`.
5. `bash os test --iso --no-build` подтвердил два цикла BIOS/GRUB-загрузки
   с сохранением данных и новым порядком запуска служб:
   `ISO_BOOT_TEST_PASSED`.

Сейчас встроена одна служба — сеть. Её скрипт и список загрузки находятся
в initramfs, поэтому их изменение требует новой сборки. `/usr/local` —
постоянное место для локальных программ, но менеджер пакетов ещё не создан.
