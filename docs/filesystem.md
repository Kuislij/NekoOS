# Файловая система начального образа

Этап 3 использует один initramfs в RAM. Сборка создаёт дерево в
`build/rootfs/`, затем упаковывает его в `out/images/initramfs.cpio.gz`.
Исходные файлы проекта лежат в `rootfs/`: `/init`, настройки `/etc/` и
короткая команда `neko-help`. Редактировать сгенерированное дерево не нужно.

## Структура

| Путь в NekoOS | Назначение |
| --- | --- |
| `/usr/bin`, `/usr/sbin` | Исполняемые программы и ссылки на applets BusyBox |
| `/bin`, `/sbin` | Ссылки на соответствующие папки в `/usr` |
| `/usr/lib`, `/usr/lib64` | Места для будущих библиотек |
| `/lib`, `/lib64` | Ссылки на соответствующие папки в `/usr` |
| `/usr/local` | Место для будущих локально установленных программ |
| `/etc` | Исходные настройки, имя ОС и учётная запись root |
| `/var/lib`, `/var/cache`, `/var/log` | Места для будущих изменяемых данных |
| `/var/run`, `/var/lock` | Ссылки на `/run` и `/run/lock` |
| `/home`, `/root` | Домашние папки; `/root` доступна только root |
| `/tmp`, `/var/tmp` | Временные файлы; права `1777` |
| `/run` | Временные данные процессов; монтируется как tmpfs |
| `/dev`, `/proc`, `/sys` | Устройства и сведения ядра; монтируются при старте |
| `/mnt`, `/media`, `/opt` | Зарезервированы, пока пустые |

Основной исполняемый файл — `/usr/bin/busybox`; applets (`sh`, `cat`, `ls`
и другие) — ссылки на него. `/usr/sbin/init` тоже ссылается на BusyBox.
Наличие `/bin` и `/sbin` сохраняет привычные пути для скриптов.

Rootfs пока не имеет постоянного диска: запись в `/var` тоже теряется после
выключения. `/tmp` и `/run` получают отдельные tmpfs. Структура создана для
дальнейшего развития, но сама по себе ещё не вводит управление пакетами,
пользователями или сервисами.

## Контроль образа

`tools/validate_image.py` разбирает настоящий cpio-архив перед запуском VM.
Проверяются обязательные файлы и каталоги, ссылки, тип и номера `/dev/console`
и `/dev/null`, права временных каталогов и `/root`, владелец и фиксированные
временные метки. `bash os test` дополнительно проверяет часть этих путей
изнутри загруженной NekoOS. Подробнее: [ADR-003](adr/0003-rootfs-layout.md).
