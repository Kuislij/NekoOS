# Проверка системного диска — 2026-09-26

Среда: WSL2 Ubuntu, QEMU x86_64 TCG. `bash os build` собрал ядро, полный
initramfs, маленький bootstrap и ext4-заготовку системного диска. Проверка
полного initramfs приняла 1425 записей. `debugfs` подтвердил владельца root
у файлов образа и символьное устройство `/dev/console` (5:1).

`bash os test --system --no-build` создал **два временных диска** и выполнил
две загрузки. Первая проверила, что корень `/` — ext4 на `/dev/vda`, диск
данных доступен как `/dev/vdb`, затем записала файл в `/etc` и другой в
`/root`. Вторая прочитала оба файла, собрала и запустила C-программу с
системного диска. В обеих загрузках виртуальная сеть получила адрес по DHCP.
Результат: `SYSTEM_TEST_PASSED`. Рабочий `state.img` тест
не подключал.

Команда `bash os system-image` создала `out/disks/system.img` и при повторном
вызове сохранила существующий файл. Затем настоящий `bash os run --system`
запустился с рабочими виртуальными дисками: консоль сообщила
`SYSTEM_DISK_READY`, `PERSISTENCE_READY`, `SYSTEM_READY`; команда `mount`
показала `/dev/vda on / type ext4 (rw,noatime)`. VM штатно выключилась.

Регрессии: прошли `BOOT_TEST_PASSED`, `NETWORK_TEST_PASSED`,
`DISK_TEST_PASSED`, `SERVICES_TEST_PASSED`, `PACKAGE_TEST_PASSED` и
`ISO_BOOT_TEST_PASSED`. BIOS ISO пересобран после изменения BusyBox.

Границы: режим проверен только в QEMU с виртуальными дисками. Сборка не
обновляет уже созданный `system.img`; перенос изменений из новой заготовки
и откат пока не реализованы. Физические диски и загрузчик Windows не
изменялись.
