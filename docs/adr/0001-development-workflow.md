# ADR-001: WSL2 и QEMU для первого цикла разработки

Статус: принято для начальных этапов. Дата: 2026-09-22.

Контекст: физический хост Windows; нужно разрабатывать Linux-based ОС,
не меняя загрузчик и диски хоста.

Решение: инструменты сборки и QEMU работают внутри WSL2; x86_64 — первая
целевая архитектура. QEMU использует TCG. Исходники сборочной копии и
результаты размещаются в Linux filesystem. Короткие сценарии пишем на Bash.

Альтернативы: QEMU на Windows добавляет передачу путей и артефактов;
KVM зависит от доступности вложенной виртуализации; полноценная Linux VM
остаётся запасным вариантом, если WSL2 нельзя подготовить.

Последствия: единая среда и простые пути, но TCG медленнее аппаратного
ускорения. Наличие WSL2 и успешные проверки — условие завершения этапа 1.
