# ADR-007: первый локальный пакет

Статус: принято для начальной части этапов 5–6. Дата: 2026-09-26.

Контекст: пользователь уже может сохранять программы в `/usr/local/bin`,
но должен копировать их вручную. Нужны проверяемый архив, учёт установленных
программ и удаление без изменения системного initramfs.

Решение: NekoPkg/1 — gzip-сжатый USTAR-архив из двух обычных файлов:
фиксированного текстового `manifest` и одного исполняемого `payload`.
Манифест ограничивает имя, версию, архитектуру x86_64, лицензию, путь,
размер и SHA-256. Зависимости в этой версии только `none`. Формат не
выполняет install-скрипты. `tar.gz` выбран потому, что BusyBox уже может
читать его без отдельной библиотеки; фиксированные строки можно разобрать
в ash без JSON/TOML-парсера. Более эффективное сжатие и многофайловый
формат потребуют следующей версии.

`neko-pkg` никогда не распаковывает пути архива прямо в системные каталоги:
проверяет ровно два имени и тип обычного файла, читает каждый элемент в
контролируемый временный каталог, сверяет размер и SHA-256. Установка идёт
только на сохранённый виртуальный диск. Под блокировкой готовый каталог
перемещается в `/usr/local/lib/neko-pkg/store/<name>`, затем создаётся
ссылка `/usr/local/bin/<name>`. Имя существующей команды не заменяется.
При следующем вызове временные каталоги и данные без ссылки очищаются;
удаление сначала снимает ссылку, потом удаляет данные. Это даёт простой
путь восстановления для одного файла, но ещё не общую транзакцию для
множества файлов или обновления версии.

Первый архив `neko-greet` включён в образ как пример. Создание своих
архивов выполняет host-скрипт `tools/make_package.py`; `packages/local/`
позволяет добавить их в initramfs при сборке. Проверка в VM выполняет
установку, перезагрузку, сверку целостности и удаление на отдельном
виртуальном диске.
