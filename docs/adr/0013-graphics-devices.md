# ADR-013: виртуальная графическая основа

Статус: принято для разработки GUI в QEMU. Дата: 2026-09-26.

Ядро NekoOS включает DRM/KMS для virtio-GPU, framebuffer-консоль и evdev для
виртуальных клавиатуры и мыши. `bash os run --graphics` подключает эти
устройства и открывает окно QEMU с 512 МиБ гостевой памяти. Последней
консолью ядра остаётся `ttyS0`; существующие команды и диагностика доступны в
терминале запуска. Обычный запуск без флага по-прежнему работает без окна.

`bash os test --graphics` загружает ту же комбинацию виртуальных устройств без
видимого окна и проверяет `/dev/dri/card0` и события ввода внутри гостя. Это
аппаратная основа для будущего композитора, а не готовый графический сеанс.
