# ADR-012: управление долгоживущими службами

Статус: принято для экспериментальной системы служб. Дата: 2026-09-26.

Ранние скрипты служб сами выполняют `start`, `stop` и `status`; для коротких
действий, таких как настройка сети, этот контракт сохранён. Скрипт с отдельной
строкой `# neko-service: foreground` выбирает другой контракт: действие `run`
запускает долгоживущую программу в переднем плане через `exec`. `neko-service`
запускает её в фоне, хранит PID и время старта процесса из `/proc` в `/run`,
а вывод отправляет в `/run/neko/services/<имя>.log`.

Операции `start`, `stop`, `restart`, `status` сериализуются блокировкой. Перед
сигналом остановки проверяются PID и время старта, чтобы устаревший файл не
задел другой процесс. Остановка сначала отправляет TERM и ждёт до пяти секунд,
затем при необходимости KILL. Настройки автозапуска остаются на диске данных;
PID и лог существуют только в текущей загрузке. Протокола готовности и
автоматического перезапуска после падения пока нет.
