# ADR-003: единый /usr в начальной системе

Статус: принято для этапа 3. Дата: 2026-09-25.

Контекст: при первой загрузке программы располагались в `/bin`, а `/usr/bin`
существовал пустым. Это создаёт два возможных места для новых пакетов.

Варианты: оставить отдельные `/bin` и `/usr/bin` с правилами размещения
или хранить программы под `/usr`, оставив классические пути ссылками.
Второй вариант проще для будущего менеджера пакетов и установки userspace.

Решение: программы размещаются в `/usr/bin` и `/usr/sbin`; `/bin`, `/sbin`,
`/lib`, `/lib64` — ссылки на соответствующие каталоги `/usr`. Mutable-данные
находятся под `/var`, runtime-состояние под `/run`. Пока весь rootfs живёт в RAM;
решение о постоянном разделе и его способе монтирования отложено.

Следствия: скрипты с `/bin/sh` продолжают работать, а одна копия BusyBox
используется всеми applets. Образ проверяется по содержимому cpio, включая
типы ссылок и права. Будущие пакеты должны считать `/usr` основным местом
установки программ.
