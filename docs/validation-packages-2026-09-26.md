# Проверка первого формата пакетов — 2026-09-26

Среда: WSL2/Ubuntu, QEMU x86_64 TCG. Сборка выполнена в Linux-копии
проекта обычным пользователем `neko`; существующий виртуальный диск
`out/disks/state.img` не форматировался.

`bash os build` создал initramfs с `neko-pkg`, утилитами BusyBox для чтения
архива и проверки SHA-256, а также встроенным пакетом `neko-greet`.
Проверка структуры приняла 1415 записей. Отдельно созданный локальный пакет
из `packages/local/` появился в новом initramfs; проверочный файл затем
удалён, окончательный образ пересобран без него.

`bash os test --package --no-build --timeout 120` использовал отдельный
временный ext4-диск и три загрузки VM. Повреждённый архив и пакет с занятым
именем команды были отвергнуты. Рабочий пакет установился, выполнился и
пережил выключение; `verify` обнаружил изменение файла. После восстановления
файла проверка снова прошла, `remove` удалил команду и данные. Третья загрузка
подтвердила отсутствие пакета и очистку каталогов незавершённой операции:
`PACKAGE_TEST_PASSED`.

Проверки базовой системы после включения пакетных applets также прошли:
`BOOT_TEST_PASSED`, `DISK_TEST_PASSED`, `NETWORK_TEST_PASSED` и
`ISO_BOOT_TEST_PASSED`. ISO пересобран из окончательного initramfs.
Пакеты пока локальные, однофайловые, без зависимостей и обновлений.
