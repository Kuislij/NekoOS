# Rootfs

Здесь находятся исходные `/init` и файлы `/etc`. Сценарий image.sh создаёт
`build/rootfs/`, добавляет статический BusyBox, ссылки на applets, каталоги
и device nodes через fakeroot, затем упаковывает всё в cpio.gz.
Этот README не включается в образ. Не запускайте guest `/init` на хосте.
Изменения в сгенерированном `build/rootfs/` будут потеряны при новой сборке.
