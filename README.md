# NekoOS

Самостоятельная Linux-based ОС для x86_64. Сейчас — подготовительный каркас,
а не загружаемая система. Рабочее название взято из имени папки проекта.

## Первый этап

Windows → WSL2 (Ubuntu) → сборка → QEMU в WSL2 → гостевая NekoOS.
Этап 1 проверяет инструменты, компиляцию C через Make и Ninja и запуск QEMU
без дисков. Ядро, initramfs и shell появятся на этапе 2.

## Быстрый старт в Linux / WSL2

Рабочую копию для сборки разместить в `~/src/NekoOS`, внутри Linux filesystem.
Текущая папка `F:\NekoOS` служит исходным каркасом на Windows.

```bash
bash scripts/bootstrap-dev.sh          # только проверка зависимостей
bash scripts/bootstrap-dev.sh --install # установка через apt, явно по запросу
bash os doctor
bash os build                         # тест компилятора, Make и Ninja
bash os run                           # тест запуска QEMU, не загрузка ОС
```

Логи сохраняются в `build/logs/`. Установка зависимостей поддерживает Ubuntu
и Debian; на другой Linux-системе скрипт перечислит недостающие команды.
Версии host-инструментов пока не закреплены: воспроизводимость байт в байт
на этом этапе не заявляется.

## Статус проверки

На 2026-09-22 дистрибутивы WSL на хосте отсутствуют; `wsl --status` сообщает,
что текущая конфигурация не поддерживает WSL2. Полная проверка первого этапа
ожидает рабочей Linux-среды. Скрипты не включают компоненты Windows и не
меняют настройки виртуализации автоматически.
